# Autonomous Ecosystem ; Concept

> Status: Established in ES-033. Semantic Version: 2.6.0.
> Base: wsf:Ecosystem (ADR-WSF-28, Baseline).

## Definition

An Autonomous Ecosystem is an Ecosystem in which coordination, adaptation, or value-realization behavior among participating entities operates without per-decision human involvement, within declared policy boundaries, authority delegations, and escalation paths. Per ES-ADR-033 section 2.

## Four-State Matrix

Ecosystem ; Agentic Ecosystem (ES-029) ; Autonomous Ecosystem (this) ; Agentic + Autonomous Ecosystem (combination).

## AI Boundary

Autonomous Ecosystem does not require AI.
