# Agentic System

Per ADR-ES-025 section 1 + CR-ES-025 section 2.

## Canonical Definition

A System in which material system behavior incorporates the interpretation of delegated intent, contextual decision selection, action coordination, adaptation, or execution toward an intended outcome within defined authority, policy, and contextual boundaries.

## Foundational Status

Agentic System is a specialization of System (canonical per ADR-ES-027 + CR-ES-027 Accepted).

## Canonical Relationships (per ADR-ES-025 section 10)

Agentic System specializes System. Agentic System engages Agent, interprets Intent, operates-within Authority, governed-by Policy, constrained-by Constraint, responds-to Context, selects Action, coordinates Action, produces Outcome, adapts-to Context, uses Agentic Workflow, supports Capability, implements Service, contributes-to Value.

## Boundary Discipline (per ADR-ES-025 section 11)

Agentic System is NOT Agent, Agentic Workflow, Agentic Operations, Agentic Service, Agentic Organization, Agentic Enterprise, Autonomous System, AI System merely because it uses AI, Automated System merely because it automates execution.

## Properties (per CR-ES-025 section 3)

system_intent, agentic_scope, system_context, delegated_intent, authority_context, policy_context, constraint_context, interpretation_scope, decision_scope, action_selection_scope, coordination_scope, adaptation_scope, intervention_model, escalation_boundary, observation_scope, realization_mode.

## Orthogonality with Autonomous System (per ADR-ES-025 section 8)

Autonomous System remains deferred per ADR-ES-022 section 13 + ADR-ES-025 section 13 (mechanical symmetry prohibition).
