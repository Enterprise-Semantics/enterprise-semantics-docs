# Agentic System Boundary

Per ADR-ES-025 + CR-ES-025 section 9.

## Boundary Statement

Agentic System is a governed specialization of System that addresses material agentic behavior at the system operating boundary, separate from Agent (single actor), Agentic Workflow (work coordination), Agentic Operations (operating environment mode), and Agentic Enterprise (enterprise-level realization).

## Boundary Identifiers

The Agentic System boundary is identified by:
- material system-level agentic behavior
- delegated intent interpretation
- contextual decision selection
- action selection + coordination
- adaptation to context
- outcome-oriented execution

## Boundary Constraints

The boundary must NOT be confused with:
- Agent (single actor)
- Agentic Workflow (work coordination)
- Agentic Operations (operating environment mode)
- Agentic Service (value delivery unit)
- Agentic Organization (organizational entity)
- Agentic Enterprise (enterprise-level realization)
- Autonomous System (deferred per ADR-ES-022 section 13 + ADR-ES-025 section 13)
- AI System merely because it uses AI
- Automated System merely because it automates execution
