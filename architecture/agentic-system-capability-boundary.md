# Agentic System / Capability Boundary

Per ADR-ES-025 section 10 + CR-ES-025 section 9.

## Boundary Statement

Agentic System supports Capability. Capability is the functional ability ; System is the structural-behavioral whole that supports the realization. Agentic System is NOT Capability.

## Conformance

Reject:
- Agentic System is-a Capability
- Capability is-a Agentic System

unless separately authorized by a governed relationship.
