# System / Workflow Boundary

Per ADR-ES-027 section 6 + CR-ES-027 section 7 + Recon-ES-004.

## Boundary Statement

System participates-in Workflow. Workflow is execution-oriented. System is structural-behavioral. System is NOT Workflow.

## Conformance

Reject:
- System is-a Workflow
- Workflow is-a System

unless separately authorized by a governed relationship.
