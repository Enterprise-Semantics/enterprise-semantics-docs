# System / Outcome Boundary

Per ADR-ES-027 section 6 + CR-ES-027 section 7 + Recon-ES-004.

## Boundary Statement

System produces Outcome. Outcome is what is produced. System is what produces it. System is NOT Outcome.

## Conformance

Reject:
- System is-a Outcome
- Outcome is-a System

unless separately authorized by a governed relationship.
