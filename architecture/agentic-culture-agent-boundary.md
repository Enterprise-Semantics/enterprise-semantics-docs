# Agentic Culture / Agent Boundary

Per ADR-ES-023 section 7 + CR-ES-023 section 10.

## Boundary Statement

Agentic Culture engages-with Agent. Culture is the shared meaning supporting agentic behavior ; Agent is the entity that performs agentic behavior.

## Conformance

Reject:
- Agentic Culture is-a Agent
- Agent is-a Agentic Culture

unless separately authorized by a governed relationship.
