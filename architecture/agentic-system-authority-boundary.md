# Agentic System / Authority Boundary

Per ADR-ES-025 section 4 + CR-ES-025 section 9.

## Boundary Statement

Agentic System operates-within Authority + Policy + Constraint + Context + Governance + Escalation. Agentic behavior is bounded ; does NOT imply unrestricted discretion.

## Conformance

Reject:
- Agentic System has unlimited authority
- Agentic System bypasses governance
- Agentic System removes accountability

unless separately authorized by a governed relationship.
