# Offering Foundation Boundary

Per ADR-ES-021 section 1 + CR-ES-021 section 11.

## Foundational Status

Offering is a foundational concept in Enterprise-Semantics. It establishes the parent concept that ADR-ES-018 (Agentic Offering) and ADR-ES-019 (Autonomous Offering) specialize.

## Foundational Discipline

This concept does NOT create:
- Customer (deferred per ADR-ES-021 section 12)
- Fulfillment Process (deferred per ADR-ES-021 section 12)
- Portfolio (deferred per ADR-ES-021 section 12)
- Solution (deferred per ADR-ES-021 section 12)
- Offering Portfolio (deferred per ADR-ES-021 section 12)

Each deferred concept requires independent semantic governance.
