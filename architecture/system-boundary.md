# System Boundary

Per ADR-ES-027 + CR-ES-027 section 7.

## Boundary Statement

System is a foundational concept with a distinct semantic boundary at the level of organized-element behavior, separate from Entity, Organization, Service, Resource, Process, Workflow, and Capability.

## Boundary Identifiers

The System boundary is identified by:
- element organization
- behavioral coherence
- defined boundary
- intended functions + purposes + outcomes
- contextual operation

## Boundary Constraints (per ADR-ES-027 section 6)

The boundary must NOT be confused with:
- Entity (too broad)
- Organization (requires people + roles)
- Enterprise (cumulative priority realization)
- Service (delivery-oriented)
- Resource (consumable)
- Process (activity sequence)
- Workflow (execution-oriented)
- Capability (functional ability)
- IT system specifically
