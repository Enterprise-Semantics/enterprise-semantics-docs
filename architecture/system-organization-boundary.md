# System / Organization Boundary

Per ADR-ES-027 section 6 + CR-ES-027 section 7 + Recon-ES-004.

## Boundary Statement

System supports Capability. Organization has people + roles. System does NOT require people. System is NOT Organization.

## Conformance

Reject:
- System is-a Organization
- Organization is-a System

unless separately authorized by a governed relationship.
