# Offering / Value Stream Boundary

Per ADR-ES-021 section 6 + CR-ES-021 section 11.

## Boundary Statement

Value Stream involves Offering. An Offering participates in a Value Stream, but an Offering is not a Value Stream.

## Conformance

Reject:
- Offering is-a Value Stream
- Value Stream is-a Offering

unless separately authorized by a governed relationship.
