# Organization / Value Stream Boundary

Per ADR-ES-022 section 8 + CR-ES-022 section 11.

## Boundary Statement

Value Stream involves Organization. An Organization participates in a Value Stream, but an Organization is not a Value Stream.

## Conformance

Reject:
- Organization is-a Value Stream
- Value Stream is-a Organization

unless separately authorized by a governed relationship.
