# System / Function Boundary

Per ADR-ES-027 section 6 + CR-ES-027 section 7 + Recon-ES-004.

## Boundary Statement

System realizes Function. Function is what is realized. System is what realizes it. System is NOT Function.

## Conformance

Reject:
- System is-a Function
- Function is-a System

unless separately authorized by a governed relationship.
