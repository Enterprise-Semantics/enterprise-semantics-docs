# Agentic System / Agentic Workflow Boundary

Per ADR-ES-025 section 6 + CR-ES-025 section 9.

## Boundary Statement

Agentic System uses Agentic Workflow. Workflow is work coordination behavior ; System is the structural-behavioral whole that may employ workflows. Agentic System is NOT Agentic Workflow.

## Conformance

Reject:
- Agentic System is-a Agentic Workflow
- Agentic Workflow is-a Agentic System

unless separately authorized by a governed relationship.
