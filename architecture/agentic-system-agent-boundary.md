# Agentic System / Agent Boundary

Per ADR-ES-025 section 5 + CR-ES-025 section 9.

## Boundary Statement

Agentic System engages Agent. Agent is the entity that performs agentic behavior ; Agentic System is the system whose material behavior incorporates agentic operation. Agentic System is NOT Agent.

## Conformance

Reject:
- Agentic System is-a Agent
- Agent is-a Agentic System

unless separately authorized by a governed relationship.
