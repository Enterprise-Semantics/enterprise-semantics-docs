# Offering / Agentic Offering Realization Boundary

Per ADR-ES-018 §1 + §2 + §3 and CR-ES-018 §3 + §13.

## Distinction

Offering represents what an organization makes available to a stakeholder or market as a coherent proposition. Agentic Offering additionally describes how the offering is realized through material agentic behavior within defined authority, policy, and contextual boundaries.

The classification depends on where the material agentic behavior resides.

## Boundary Preservation

- Agentic Offering retains the semantic identity of Offering (per ADR-ES-018 §1 + AOFF-CON-002)
- Agentic Offering does NOT redefine Offering (per ADR-ES-018 §1)
- Agentic behavior is a contextual specialization, NOT a replacement

## Foundational Dependency

Per ADR-ES-018 §16, this ADR does NOT establish the complete semantic definition of Offering. The parent Offering concept remains to be canonicalized via ADR-ES-019 (next-foundational tranche).

## Materiality

Per ADR-ES-018 §5 + §13 + CR-ES-018 §13:

- Insufficient: Offering + AI / Offering + automation / Offering + chatbot / Offering + Agent somewhere in implementation
- Potentially Agentic: Offering + stakeholder intent interpretation + contextual evaluation + bounded authority + dynamic composition/configuration + action selection + coordination + adaptation
