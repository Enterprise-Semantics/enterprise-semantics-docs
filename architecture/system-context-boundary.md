# System / Context Boundary

Per ADR-ES-027 section 6 + CR-ES-027 section 7 + Recon-ES-004.

## Boundary Statement

System operates-within Context. Context is the environment. System is the organized whole operating within Context. System is NOT Context.

## Conformance

Reject:
- System is-a Context
- Context is-a System

unless separately authorized by a governed relationship.
